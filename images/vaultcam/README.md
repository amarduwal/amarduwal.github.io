# VaultCam images

- logo-512.png, logo-128.png, favicon.png: the VaultCam launcher icon, exported from the app repo (design/brand/out/icon-play.png).
- qr-khalti.png, qr-esewa.png, qr-paypal.png: the owner's payment QR codes, cropped to the code only (the Khalti and eSewa codes still carry the wallet ID and name, which the wallets need).
- qr-crypto.png: generated from the BNB Smart Chain (BEP20) address shown on vaultcam/support.html. One address receives BTC (BEP20) and USDT (BEP20).
